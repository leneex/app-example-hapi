# Hapi

Пример приложения [Hapi](https://hapi.dev/), которое можно развернуть без настройки.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Railpack |
| Путь до директории проекта | `/` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Команда запуска | оставьте пустым |
| Порт приложения | `3000` |
| Путь проверки состояния | `/` |

Railpack ставит зависимости и запускает `npm run start`. Приложение слушает порт из переменной
окружения `PORT` — её передаёт платформа, — а без неё `3000`.

## <a name="dev"></a>Локальный запуск проекта

```bash
# установка зависимостей
npm install

# запуск приложения
npm run start
```
