# Hapi

Example [Hapi](https://hapi.dev/) app. Hapi is a Node.js framework for building scalable APIs and web applications.

## Deploy settings

| Field | Value |
| --- | --- |
| Build | Railpack |
| Project directory | `/` |
| Install command | leave empty |
| Build command | leave empty |
| Start command | leave empty |
| Application port | `3000` |
| Health check path | `/` |

## <a name="dev"></a>Run locally

```bash
# install dependencies
npm install

# start the app
npm run start
```
